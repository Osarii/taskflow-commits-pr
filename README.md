# TaskFlow

TaskFlow es una aplicación web sencilla para organizar tareas personales.  
El proyecto fue desarrollado con HTML, CSS y JavaScript puro como parte de un laboratorio de Git, Conventional Commits y Pull Requests.

## Funcionalidades actuales

- Agregar nuevas tareas.
- Validar que el texto no esté vacío.
- Validar una longitud mínima de 3 caracteres.
- Limitar las tareas a 120 caracteres.
- Normalizar espacios innecesarios.
- Mostrar las tareas dentro de la página.
- Mostrar mensajes de error en el formulario.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
